# 发布前的自查参考（按需查阅）

**这不是流程的一部分，助手不会主动用它筛文案、也不会拿它拦你的稿子。**

只有在用户主动问「这些词能不能发」「平台会不会限流」「哪些表述要小心」的时候，才翻这份文档给参考。用户没问，就不要提。

## 用户可能问的三类问题

### 「哪些词平台敏感」

平台侧比较常见的高压词，供参考（不是禁用清单，具体以用户自己的账号经验为准）：

- 绝对化表述：国家级、世界级、最高级、最佳、全网最低、销量第一、NO.1、绝对有效、百分百、纯天然、无副作用
- 功效承诺：治疗、根治、消炎、止痛、疗效、药效、医用、处方、包治、痊愈、防癌
- 商业承诺：包邮、顺丰、赠品、7天无理由、假一赔十（除非产品页写明）

### 「哪些句式容易踩线」

116 个结构里，以下几类句式自带某种叙事立场，用户如果不具备对应情况，写出来会显得不真实：

| 句式类型 | 代表 rank | 自带立场 |
|---|---|---|
| 自家工厂 / 不给二道贩子 / 直供价 | 68、100 | 自产自销 |
| 维权成功 / 仅此一家正版 | 93 | 品牌方或独家授权 |
| 同行还在抄 / 你抄得没我快 | 6、35 | 曾被抄袭 |
| 和爸妈商量定价 / 爷爷做了几万件 | 29、49、57、100、109 | 家族生意 |
| 顾客祝我永不倒闭 / 客户返图 | 54、86 | 有真实客户互动 |
| 改了又改做出来 / 关于我做了XX | 30、40、41、64、115 | 自主设计生产 |

**用途**：用户如果问「这句是不是得真被抄过才写」，可以指给他看。但不要主动在交付时说「这几条有风险」——那是用户自己的判断。

### 「按品类有什么讲究」

| 品类 | 常见注意点 |
|---|---|
| 美妆个护 | 美白/祛斑/祛痘/抗衰通常需要特证；「药妆」多数平台禁 |
| 食品饮品 | 保健功效（降血糖/减肥/助眠）属功能宣称，普通食品只描述口感 |
| 母婴 | 「最安全」「零添加」类表述易被要求举证 |
| 家居枕具 | 描述支撑感、舒适度可以，宣称改善颈椎腰椎病属于疗效 |
| 服饰 | 「显瘦」可以，「减肥」不可以；真丝/羊绒成分需与吊牌一致 |
| 数码 | 续航/参数与官方规格对齐 |
