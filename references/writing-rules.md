# 怎么写才像人话

爆款标题的「爆」不在词藻，在**说话的方式**。同一句话换个说法就不像小红书了。这份文档是填槽位时的语感校准。

## 一、这些标题的共同语法

拆开 116 个结构，真正让人想点开的动作只有五种：

| 动作 | 机制 | 例子 |
|---|---|---|
| **反差** | 预期被打碎 | 「以为要一百多。。。结果39.9」 |
| **具体** | 抽象变可量 | 「穿一次被夸三天」而不是「很显气质」 |
| **共情** | 说出对方没说出口的感受 | 「侧睡的时候腰是悬空的」 |
| **稀缺** | 制造错失感 | 「唯一的缺点：只有小号还在」 |
| **身份** | 让人找到自己 | 「请大数据推给所有侧睡党」 |

填槽位前先问自己：这条在用哪个动作？五个都没有，就是白写。

## 二、语感细则

### 标点是语气的骨架

- `。。。` 拖长音，表示无奈、欲言又止、克制。「以为很贵。。。。结果一箱才8r」
- `！！！` 情绪冲顶，但要节制，一篇里别超过两条用
- `？？？` 震惊或反问，适合吐槽式结构
- `，` 短句连打，制造喘气感。「垫子上腰，腰就不空了，真的」
- `（）` 括号里放补充、自嘲、内心 OS，这是小红书最有辨识度的写法

### 口语词表（可替换进文案）

真的 / 属实 / 其实 / 压根 / 明明 / 结果 / 居然 / 就 / 才 / 才…而已 / 说真的
妈呀 / 天呐 / vocal / 啊这 / 救命 / 谁懂 / 讲真 / 别问 / 问就是

语气词收尾能给文案「落地」的感觉：…啊、…呢、…吧、…诶、…啦

### 数字要比形容好

| 弱 | 强 |
|---|---|
| 很便宜 | 39.9 |
| 用很久了 | 用了半年 |
| 很多人问 | 被追着问了三天 |
| 很软 | 捏下去像没骨头 |

数字、时长、次数、人数——能量化的一律量化。这是 116 个结构里出现频率最高的技巧。

### emoji 是节奏不是装饰

- 放句尾当尾音：`软软乎乎的☁️`
- 放句中当停顿：`39.9💰一只`
- 三个以内，多了显廉价
- 与产品色系呼应：蓝白 → 🩵🤍☁️；食物 → 🥣🍞

## 三、三条一组的配比

同一结构出 3 条，按这个思路分配，避免同质化：

**方案 A｜按卖点切**（最常用）
价格 → 材质/手感 → 场景/痛点

**方案 B｜按人群切**
侧睡党 / 久坐族 / 出差党

**方案 C｜按情绪强度切**
强冲击（价格惊呼）→ 中（对比吐槽）→ 弱（温柔陈述）

不要三条都用同一个卖点说三遍——那是重复，不是覆盖。

## 四、自检七个问题

交付前逐条过：

1. 念出声，会不会卡壳？卡壳就是不通顺。
2. 有没有一个具体数字或具体场景？没有就补。
3. 第一眼能不能看懂是什么产品？看不懂就该把品类词塞进去。
4. emoji 是不是超过三个？
5. 三条之间有没有实际差异（卖点/人群/情绪）？
6. 换成别的产品还能不能用？能用说明没写出产品特性。
7. 有没有「最/第一/唯一」以外的绝对化表述？（这些可保留，其他违禁词不行）

## 五、反面样例

| 别这样写 | 问题 | 改成 |
|---|---|---|
| 高品质护腰枕，舒适透气 | 全是形容，没有画面 | 垫上再也不用手塞腰底下了 |
| 超值推荐！性价比超高 | 空话，谁都能说 | 39.9，比之前买的一百多的还贴腰 |
| 采用羽丝棉材质，柔软舒适 | 说明书语言 | 捏下去像没骨头，软得不想拿开 |
| 适合各种人群使用 | 没有靶心 | 侧睡党听我喊：侧卧有支撑 |
| 亲们快来看这个好东西 | 求关注，没给理由 | 被同事追着问了三天链接 |

## 六、关于「夸张」的边界

允许夸张的：感受强度（「舒服到说不出话」）、情绪反应（「进太庙吧」）、时间体感（「一觉睡到自然醒」）。

不允许夸张的：功效承诺、价格真实性、销量数字、材质成分、售后条款。这类必须与产品卡一致，宁可少写不可瞎写。
